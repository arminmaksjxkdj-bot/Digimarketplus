# دیجی مارکت (DiJi Market)

بازار محلی برای فروشنده‌های ماینکرفت — جایی برای ثبت آگهی فروش اکانت، رنک، آیتم، دنیا، اسکین و پلاگین، با هماهنگی نهایی از طریق دیسکورد.

## فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل و طراحی
- `script.js` — منطق سایت (آگهی‌ها، فیلتر، جستجو، فرم ثبت آگهی)
- `firebase-config.js` — تنظیمات اتصال به دیتابیس مشترک (Firebase)
- `logo.png` — لوگوی سایت

## چرا آگهی‌ها قبلاً سیو نمی‌موند؟

نسخه‌ی اول این سایت کاملاً استاتیک بود و آگهی‌ها فقط داخل مرورگر خود کاربر (`localStorage`) ذخیره می‌شدن. یعنی هرکس آگهی می‌ذاشت، فقط خودش می‌دیدش و بقیه‌ی بازدیدکننده‌ها یا حتی خودش با یه مرورگر/گوشی دیگه، اون رو نمی‌دیدن.

**الان این مشکل حل شده:** سایت به یه دیتابیس واقعی و رایگان به اسم Firebase Firestore وصل می‌شه که آگهی‌ها رو برای همه‌ی بازدیدکننده‌ها مشترک نگه می‌داره. تا وقتی تنظیماتش رو انجام ندی، سایت خودکار برمی‌گرده به همون حالت محلی قبلی (که برای تست کردن مشکلی نداره).

## راه‌اندازی دیتابیس مشترک (Firebase) — رایگان، بدون نیاز به کارت بانکی

۱. برو به [console.firebase.google.com](https://console.firebase.google.com) و با یه حساب گوگل وارد شو.
۲. روی **Add project** بزن، یه اسم بذار (مثلاً `dijimarket`) و پروژه رو بساز (می‌تونی Google Analytics رو غیرفعال بذاری).
۳. توی منوی سمت چپ پروژه، برو روی **Build → Firestore Database** و روی **Create database** بزن.
   - حالت رو روی **Start in test mode** بذار (برای شروع کافیه؛ نکته‌ی امنیتی پایین صفحه رو هم بخون).
   - یه لوکیشن نزدیک به کاربرات انتخاب کن و تأیید کن.
۴. برگرد به صفحه‌ی اصلی پروژه (آیکون خونه)، روی آیکون **</> (Web)** بزن تا یه اپ وب جدید بسازی.
   - یه اسم دلخواه بذار و **Register app** رو بزن.
   - Firebase یه شیء `firebaseConfig` بهت نشون می‌ده شبیه این:
     ```js
     const firebaseConfig = {
       apiKey: "AIza...",
       authDomain: "dijimarket-xxxx.firebaseapp.com",
       projectId: "dijimarket-xxxx",
       storageBucket: "dijimarket-xxxx.appspot.com",
       messagingSenderId: "...",
       appId: "..."
     };
     ```
۵. مقادیر داخل فایل `firebase-config.js` رو با همین مقادیر جایگزین کن (فقط داخل `firebaseConfig`، بقیه‌ی فایل رو دست نزن).
۶. فایل‌ها رو (دوباره) روی گیت‌هاب آپلود/پوش کن. از این به بعد هر آگهی‌ای که ثبت بشه، برای همه‌ی بازدیدکننده‌ها به‌صورت آنی نمایش داده می‌شه.

### نکته‌ی امنیتی مهم درباره‌ی «Test mode»

حالت Test mode فایراستور به مدت ۳۰ روز به همه اجازه‌ی خوندن و نوشتن می‌ده و بعدش خودکار قفل می‌شه. برای اینکه سایتت همیشه کار کنه، بعد از ساخت دیتابیس برو به تب **Rules** توی Firestore و این قانون رو جایگزین کن تا فقط اجازه‌ی ثبت آگهی جدید و خوندن آگهی‌ها داده بشه (نه پاک کردن یا دستکاری آگهی‌های دیگران):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /listings/{listingId} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if false;
    }
  }
}
```

## انتشار روی GitHub Pages

۱. یک ریپازیتوری جدید به اسم `dijimarket` (یا هر اسمی که دوست داری) بساز.
۲. تمام فایل‌های بالا رو داخلش آپلود کن (یا با گیت push کن).
۳. برو به تنظیمات ریپازیتوری → بخش **Pages**.
۴. از قسمت Source، برنچ `main` و پوشه‌ی `/ (root)` رو انتخاب کن و ذخیره کن.
۵. بعد از چند دقیقه، سایت روی آدرسی شبیه این در دسترس قرار می‌گیره:
   `https://username.github.io/dijimarket/`
