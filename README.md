# دیجی مارکت (DiJi Market)

بازار محلی برای فروشنده‌های ماینکرفت — جایی برای ثبت آگهی فروش اکانت، رنک، آیتم، دنیا، اسکین و پلاگین، با هماهنگی نهایی از طریق دیسکورد.

## فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل و طراحی
- `script.js` — منطق سایت (آگهی‌ها، فیلتر، جستجو، فرم ثبت آگهی)
- `logo.png` — لوگوی سایت (توی هدر و فوتر استفاده می‌شه)

## وضعیت فعلی

- لینک دیسکورد روی `https://discord.gg/5Vj3547pN` تنظیم شده (داخل `script.js`، متغیر `DISCORD_INVITE`). اگه لینکت عوض شد، همینجا آپدیتش کن.
- اگه دوست داری، آگهی‌های نمونه‌ی داخل `SEED_LISTINGS` رو حذف یا با آگهی‌های واقعی جایگزین کن.

## انتشار روی GitHub Pages

۱. یک ریپازیتوری جدید به اسم `dijimarket` (یا هر اسمی که دوست داری) بساز.
۲. این سه فایل رو داخلش آپلود کن (یا با گیت push کن).
۳. برو به تنظیمات ریپازیتوری → بخش **Pages**.
۴. از قسمت Source، برنچ `main` و پوشه‌ی `/ (root)` رو انتخاب کن و ذخیره کن.
۵. بعد از چند دقیقه، سایت روی آدرسی شبیه این در دسترس قرار می‌گیره:
   `https://username.github.io/dijimarket/`

## محدودیت مهم

این نسخه یک سایت کاملاً استاتیکه و آگهی‌های ثبت‌شده فقط داخل مرورگر خود کاربر (`localStorage`) ذخیره می‌شن — یعنی اگه یه نفر آگهی ثبت کنه، بقیه‌ی بازدیدکننده‌ها اون آگهی رو نمی‌بینن، چون سرور و دیتابیس مرکزی وجود نداره.

برای اینکه آگهی‌ها واقعاً بین همه‌ی کاربرا مشترک باشه، لازمه یه بک‌اند/دیتابیس واقعی (مثلاً Firebase, Supabase یا یک سرور اختصاصی) بهش اضافه بشه. اگه بخوای، می‌تونم در قدم بعدی این بخش رو هم برات اضافه کنم.
